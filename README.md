# Bank Management System (BMS)

A **Command-Line Python Bank Management System** with MySQL integration, user authentication, transactions, and logging.  
Created by **Arham Khan**.

## Features
- User signup/login/forgot password
- Deposit and transfer money
- Fixed Deposit calculation
- Account statement generation
- Admin panel for employees
- Logging of all actions

## Tech Stack
- Python 3.x
- MySQL (local)
- CSV for transaction records
- Pickle for logs

## Setup
1. Install Python 3.x and pip
2. Install dependencies: `pip install -r requirements.txt`
3. Create MySQL database (program auto-creates if not exists)
4. Run the program: `python bank_system.py`

## Usage
- Run in terminal/command prompt for best experience.
- Default admin accounts included.
- Transactions stored in CSV files.
